Hier nur Musik ablegen, für die eine Lizenz zur Nutzung auf TikTok vorliegt.

Jede Datei braucht eine Lizenzdatei daneben, sonst wird sie ignoriert:
  meinsong.mp3
  meinsong.license.txt   (Quelle, Lizenz, Link zum Lizenznachweis)

Musik wird nur verwendet, wenn BBOB_MUSIC_ENABLED=true gesetzt ist.
